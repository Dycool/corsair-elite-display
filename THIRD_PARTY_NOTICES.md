# Third-party notices

## Virtual Display Driver

The standalone executable contains the signed x64 MttVDD virtual display driver by the
[Virtual Display Driver project](https://github.com/VirtualDrivers/Virtual-Display-Driver),
which is distributed under the MIT License. The driver is derived from Microsoft's
Indirect Display Driver sample; see the upstream project for its complete notices and
source code.

Code signing for the bundled driver is provided by SignPath Foundation.

## DevCon

The executable contains Microsoft's DevCon command-line utility solely to create the
root-enumerated MttVDD device during the user-initiated administrator installation.
